This is the official repository for FIGMA : Fine-tuning a Fashion Domain Image Generation Model Using Self-Instruct.


# Python Package

```bash
pip install FIGMA
```
or from source 

```bash
git clone https://github.com/Gayeon6423/FIGMA.git
cd FIGMA
pip install -e .
```

## Environment
To set up the training and evaluation environment, run the bash script setup.sh that you can find at top level in this repository. This script will handle the creation of a new conda environment and will take care of all the requirements.

Simply run on the command line:
```
source ./setup.sh
```
